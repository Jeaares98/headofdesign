# Head of Design

A Codex-ready design leadership system for Colortreat and its ventures.

## Purpose
This repository defines a reusable Head of Design agent that can research, critique, direct, and help implement digital products across brand, UX, UI, interaction, motion, and game-inspired experience design.

## Start here
Codex should read `AGENTS.md` first. Specialized workflows live under `skills/`, and product-specific context belongs in `knowledge/`.

## Initial skill set
- UI/UX critique
- visual direction
- motion design
- gaming UX
- design research
- design systems
- conversion UX
- Figma handoff

## Working model
1. Frame the user and business problem.
2. Research relevant references and patterns.
3. Extract mechanisms rather than copying visuals.
4. Define a design direction.
5. Critique it against usability, distinctiveness, emotion, accessibility, and feasibility.
6. Deliver implementation-ready guidance.

## Expansion
Add new repeatable capabilities as individual skills. Keep project-specific facts out of the global agent instructions and place them under `knowledge/`.
