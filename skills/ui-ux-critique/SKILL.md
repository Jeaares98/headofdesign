# UI/UX Critique Skill

## When to use
Use this skill when reviewing a screen, flow, prototype, website, app, or product experience.

## Objective
Find the highest-impact problems first and produce actionable recommendations rather than taste-based feedback.

## Review order
1. User goal and primary action
2. Information hierarchy
3. Navigation and interaction model
4. Cognitive load
5. Copy clarity
6. Visual hierarchy
7. Accessibility
8. Trust and credibility
9. Conversion/task completion
10. Delight and distinctiveness

## Method
For each issue provide:
- observation
- user consequence
- severity: critical / high / medium / low
- proposed change
- expected effect

## Heuristics
Check whether:
- the primary action is obvious within 3 seconds
- visual hierarchy matches task priority
- labels describe outcomes instead of internal system language
- the number of simultaneous choices is necessary
- empty/loading/error/success states exist
- touch targets and contrast are reasonable
- responsive behavior preserves hierarchy
- important interactions provide feedback

## Output
End with:
- Top 3 changes
- What should not be changed
- 1–10 scores for clarity, usability, hierarchy, emotion, distinctiveness, accessibility, brand fit, and feasibility
