# Visual Direction Skill

## Purpose
Create a distinctive visual direction that expresses product strategy and brand character instead of defaulting to generic UI aesthetics.

## Inputs
Establish:
- audience
- product category
- brand personality
- emotional target
- context of use
- content density
- accessibility constraints

## Direction system
Define:
- typography character and hierarchy
- spacing rhythm
- grid behavior
- color roles
- shape language
- iconography
- imagery / photography / illustration direction
- surface treatment
- motion personality
- signature visual moments

## Contrast test
A strong direction should answer:
- What makes this recognizably ours?
- What should never appear in this brand?
- Which 2–3 visual mechanisms carry most of the identity?
- Can the system work across product, marketing, social, and presentation surfaces?

## Avoid
- trend stacking
- decorative complexity without hierarchy
- copying a reference's surface style without its underlying context
- sacrificing legibility for art direction

## Deliverable
Provide a concise creative thesis plus concrete rules that another designer or developer can execute consistently.
