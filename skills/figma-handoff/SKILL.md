# Figma Handoff Skill

## Purpose
Translate design intent into implementation-ready Figma structures and developer handoff.

## Structure
Prefer:
- reusable components
- explicit variants
- semantic naming
- Auto Layout where appropriate
- design tokens for color, spacing, radius, typography, and elevation
- responsive constraints instead of fixed-position mockups

## Handoff checklist
Include:
- component states
- hover/focus/pressed/disabled/loading/error/success states where relevant
- spacing rules
- responsive behavior
- content overflow behavior
- empty states
- accessibility notes
- motion notes
- implementation dependencies

## Rule
A polished static frame is not considered complete if developers still need to guess interaction or responsive behavior.
